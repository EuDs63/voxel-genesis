# Voxel Genesis · 极昼晶体版改版记录与优化方向

## 判断

项目已经有扎实的模拟内核：26 邻居细胞自动机、确定性的递归世界、分步撤销、局部绘制、可取消的形态育种、存档和分享。本轮将视觉中心明确交给连续的晶体雕塑，以冷白空间、冰蓝材质和银色反射呈现形态，工作台默认收起，观察和编辑按需切换。

## 本轮已实现

- **视觉体系**：冷白底色、冰蓝晶体、银色高光与深蓝文字；衬线标题、等宽数据和轻量分隔线共同形成展览式版面。标志、网站图标和中英文文案同步更新。
- **默认作品**：Continuum / 无尽之结，种子 ID 为 `torus-knot`。40³ 空间中的 2,166 个存活细胞构成具有厚度的连续三叶环结，采用 `B10/S10-26`，初始暂停。已有会话或有效分享链接仍优先恢复。
- **晶体舞台**：体素使用共享的圆角几何与 `MeshPhysicalMaterial`，结合透射、清漆和一次生成的 PMREM 棚拍环境形成反射；方向光阴影提供自阴影。辉光默认关闭，保留手动开启入口。画布跟随实际容器尺寸，镜头按形态投影自动取景。
- **展开与聚合**：舞台入口可以平滑拉开或收回细胞之间的距离，仅改变显示位置，不改写细胞状态、年龄或模拟规则。展开时从绘制切回环视，射线拾取边界随显示更新；减少动态效果偏好下直接切换。
- **操作层级**：工作台默认收起，舞台提供播放、展开 / 聚合和打开工作台。观察入口返回环视并收起工作台，创作与实验入口打开相应工具。首次引导是可关闭的小提示，精选作品保留在下方。
- **可玩的典藏**：精选为 Continuum、Torus、Menger、Wave。Continuum 使用 40³ 与 `B10/S10-26`，Torus 使用 `B3/S4-6`，其余两项使用已有预设；后三项为 24³。四组组合均检查了前 20 代持续有存活细胞，不承诺永久存活。Gyroid / 螺旋曲面仍可从图鉴选择。
- **真实数据**：代数、存活数量、空间占有率、实际规则与趋势同步展示，密度条代表实际占有率。
- **交互修复**：原生按钮的空格操作不会被全局播放快捷键劫持；聚焦作品保持可用；图鉴弹窗不再依赖固定标题高度；手机横屏单独布局。
- **工程修复**：释放 bloom 各 pass 的 GPU 资源；修正预设镜头被自动取景取消的问题；保存的环境和配色状态正确反映在界面；切换语言不会清空拖影。

原有绘制、干预、撤销、递归探索、存档、导入导出与分享仍然保留。自动机的 26 邻居同步更新算法和已有存档协议保持兼容；新增的是默认种子、场景规则配置与显示交互。配色沿用原有内部 ID，默认外观更新为晶体。线上部署沿用现有 GitHub Pages 工作流。

## 下一步优先级

1. **晶体渲染的性能预算**：默认已是 40³，需在代表性的桌面与移动设备上分别测量模拟、矩阵更新、圆角几何、透射、阴影、拖影与后处理开销。一个 `InstancedMesh` 共享几何和材质，但透射与阴影仍增加渲染工作，不能等同于整个画面仅一次绘制。基于测量再决定邻居索引缓存及 Worker 的收益。
2. **按需渲染与自适应质量**：先建立性能基线，再按设备表现调节透射质量、阴影分辨率、像素比、拖影预算和可选辉光，并保留手动选择。暂停且相机、展开动画及转场均静止时可停止无效帧。当前尚未实现自动质量档位，不承诺固定帧率。
3. **作品导演模式**：提供经过验证的规则、种子与镜头时间线，支持短片导出和过程回看，让实验结果更容易分享。
4. **模块边界**：继续把 `App` 中的作品库、递归导航、育种流程独立成服务，减少大文件和 DOM 绑定耦合。
5. **加载性能**：第二版生产 JavaScript 为 702.64 kB，gzip 为 182.95 kB，仍触发大包提醒。分析物理材质、圆角几何、PMREM 环境与后处理的依赖和初始化开销，再按实际加载收益分包。

## 验证

- 第二版在 Node 24 环境下 110 项测试全部通过，TypeScript 检查与最终生产构建通过。构图测试覆盖横竖屏、薄圆环、立方体、正俯视和预设镜头朝向；交互测试覆盖舞台操作、展开状态、工作台入口以及沉浸前后辅助线和干预标记的可见性恢复。
- 浏览器复核范围：默认连续环结、晶体反射与自阴影、展开 / 聚合、作品切换、播放 / 暂停 / 重启、图鉴分类与搜索空态、沉浸与 Escape 返回、工作台开合、中英文和响应式布局。
- 重点布局：1440 × 900 桌面、390 × 844 手机竖屏、844 × 390 手机横屏；图形表现和性能仍应覆盖实际设备。
- 系统原有 Node 20.14 低于项目要求。项目支持 Node `^20.19.0` 或 `>=22.12.0`；本轮验证使用环境已提供的 Node 24，未修改系统安装。
